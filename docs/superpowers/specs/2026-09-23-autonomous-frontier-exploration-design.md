# 自主探索建图设计

## 目标

网页点击“开始建图”后，小车自主探索房间并持续扩展 SLAM 地图。用户可以看到探索状态、暂停或停止任务；导航异常、传感器数据过期或安全门控失效时，小车必须停车。

路线图阶段 2 已将边缘优先自主探索列为目标。本设计补齐其执行闭环，并明确网页按钮会导致真实底盘移动。

## 当前根因与运行约束

- `POST /api/v1/mapping/start` 只启动 SLAM；`POST /api/v1/navigation/exploration/next` 只生成前沿路径预览。
- `rover_navigation` 当前没有 Nav2 action client，导航 launch 也没有启动 Nav2。
- 真机 ROS 图中安装了 Nav2 包，但没有导航 action；`YB_Car_Node` 直接订阅 `/cmd_vel`。
- `/cmd_vel_safe` 和 `/emergency_stop` 当前不存在，安全节点尚未形成可用的速度门控链路。

因此，不能把前沿预览直接转换为速度命令，也不能在安全速度链路尚未验证时开放自动移动。

## 交互与边界

网页“开始建图”作为一键自主探索建图入口。按钮附近明确提示点击后小车会自主移动。语音接口原有的“开始建图”仍只启动 SLAM，不隐式开启移动任务；独立 `/mapping/start` API 继续表示纯建图。

活动任务显示阶段、当前目标、成功/失败前沿数和停止原因。用户可以暂停或停止；暂停/停止会取消 Nav2 当前目标，并要求安全门控立即输出零速度。任务在没有可达前沿、地图/位姿/雷达数据过期、Nav2 action 不可用或安全检查失败时停止继续探索。

## 架构

1. Web 通过新的自主探索任务 API 启动组合任务。任务协调器启动或复用 SLAM 会话，并等待新鲜 `/map`、`/scan`、`/odom`、必要 TF 和有效 map 位姿。
2. Nav2 生命周期节点使用 SLAM 实时地图和现有 TF 树启动。开始运动前，协调器必须确认导航 action、控制器和安全门控均处于活动状态。
3. `rover_navigation` 探索器从占据栅格生成边界前沿候选，先过滤 keepout/虚拟墙、机器人安全半径和不可达区域，再按可达性与进度选择目标。
4. 探索器只调用 Nav2 `NavigateToPose` action，不发布底盘速度。导航结果成功后重新读取地图并选下一个前沿；失败或超时目标加入带退避的失败集合，避免循环重试。
5. 速度单一出口由安全节点拥有：Nav2 自动速度和现有遥控速度经仲裁、雷达避障、急停和 watchdog 后，才输出给底盘 `/cmd_vel`。不得存在绕过安全出口的第二个 `/cmd_vel` 发布者。
6. API 暴露探索状态、启动、暂停、恢复、停止和错误原因；前端把组合任务与纯 SLAM 状态区分显示。

## 预检与安全不变量

开始自动移动前必须验证：雷达/里程计/IMU 数据新鲜；`map -> odom -> base` TF 和 map 位姿有效；地图持续更新；Nav2 生命周期和导航 action 已就绪；安全门控与底盘速度出口连接正确；急停清除且 watchdog 可用。任何一项不满足都拒绝启动并显示具体原因。

安全门控默认禁止运动。雷达、位姿、mapping 状态、Nav2 命令或安全状态超时、急停触发、用户停止、节点退出时，输出零速度并取消活动导航目标。底盘命令超时停车行为必须在真机上验证；若硬件不能保证此行为，自动探索保持禁用。

keepout、虚拟墙和安全限速由 Nav2 costmap 与安全门控共同执行。探索器和 API 不得绕过这些约束，也不得直接发布速度。

## 探索行为

- 优先选择已知自由空间与未知空间交界处、可达且风险低的前沿。
- 逐步扩展可见外墙和障碍边界，继续处理门口、转角和边界断点。
- 动态障碍导致暂时不可达时等待或换目标；反复失败的候选点降权并在本次任务中暂时屏蔽。
- 无可信可达候选点时结束任务并报告未探索区域，而不是持续原地重试。
- 暂停、恢复和停止操作始终优先于探索调度；恢复前重新执行传感器、定位和导航预检。

## 验证与验收

离线验证包括：候选前沿生成/排序和 keepout 过滤；Nav2 action 成功、拒绝、超时、取消；前沿失败退避；过期 map/scan/pose、急停和 watchdog 失效时零速度；任务 API 状态机；网页按钮、状态、暂停和停止闭环；launch 中 Nav2 lifecycle/action 与唯一速度出口契约。

真机验收在人工看护、可立即断电/急停的安全场地进行。验收需要证明：点击网页入口后地图随实际运动持续扩展；小车能到达多个可达前沿；窄道、死胡同和动态障碍不会导致危险命令；keepout 生效；点击暂停/停止或断开必要状态后底盘停车；完成或停止时页面显示真实结果。未完成真机验收前，产品不得显示自动探索“可用”。

## 不在本次范围

- 语音直接触发自主移动；
- 基于摄像头的房间语义理解或完整 3D SLAM；
- 让现有手工路径预览接口直接执行；
- 以 API 内的 A* 路点跟随替代 Nav2。
